# Flowly Project Blueprint

**Prepared:** 27 October 2026  
**Scope:** Flowly bilingual AI, software and automation website, hosted preview and EC2 distribution.  
**Status key:** Implemented = present in the website or portable distribution; Planned = requires a real provider, legal review, commercial decision, or delivery engagement.

## Key risks
| Risk | Mitigation | Status |
|---|---|---|
| Unconfigured integrations create false expectation | Explicit provisional wording and readiness checklist | Controlled |
| OSS license misuse | Version-specific legal review in each proposal | Open gate |
| Customer data exposure | Scoped public lookup, owner access, no sensitive-data guidance | Controlled |
| EC2 data loss | Backups and restore test | Open gate |
| AI hallucination | Constrained catalog, fallback, human discovery | Controlled |
| Public-sector requirements vary | Institutional brief + scoped discovery | Controlled |
