# Flowly Project Blueprint

**Prepared:** 27 October 2026  
**Scope:** Flowly bilingual AI, software and automation website, hosted preview and EC2 distribution.  
**Status key:** Implemented = present in the website or portable distribution; Planned = requires a real provider, legal review, commercial decision, or delivery engagement.

## Evaluated building blocks
| Project | Fit | Licensing checkpoint |
|---|---|---|
| n8n | Workflow automation | Sustainable Use License; review commercial/embedding use. |
| Dify | AI application orchestration | Modified Apache 2.0; review multi-tenant restrictions. |
| ERPNext | ERP platform | Review current GPL obligations and distribution model. |
| Chatwoot | Customer messaging | Review current license and hosted/embedded model. |

Every client proposal needs version-specific license, hosting, data-processing and support review. A product being source-available does not make every commercial use unrestricted.
