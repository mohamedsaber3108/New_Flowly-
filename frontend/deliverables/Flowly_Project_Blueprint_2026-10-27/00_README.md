# Flowly Project Blueprint

This is the delivery blueprint for the live Flowly website. It records the current implementation, safe next work, and operational gates. It does not claim that unconfigured integrations, certifications, customer proof, pricing, or service delivery capacity are already live.

## Product snapshot
- Bilingual English/Arabic React experience with RTL, light and dark modes.
- 45 services across AI, operations, growth, creative, engineering, public sector and white-label delivery.
- Guided discovery, consultation request, government route, request tracking and an AI service-discovery assistant.
- Hosted preview with D1; portable React/Node/SQLite package for EC2.

See `37_EXISTING_CODE_AUDIT_AND_SAFE_CHANGE_PLAN.md` for what changed in this release and `35_REQUIREMENTS_TRACEABILITY.md` for requirement coverage.
